## 実画像の判定

基本動作の成功と画質・指定遵守を分け、保存済みPNGを実際に見て評価した。評価者はCodex（GPT-6、詳細ビルドは未取得）で、評価指示とそのSHA256、基準の版、画像、実行グラフを評価APIへ追記した。外部の評価APIは呼んでいない。

- 1人画像では、銀髪、緑の上着、砂地での着座を確認した。これは主要な視覚項目の確認であり、人物同一性や画質全体の達成ではない。
- 二人画像は不合格。前景で識別できる人物が1人で、その人物へ双方の服装が混ざった。背景の見切れた人物を、指定した主人公と相手の二人として数えなかった。

原入力と保存グラフには、主人公と相手の別々の外見・服装・姿勢が存在し、グラフの内容ハッシュも一致した。保存・転送による欠落は検出しなかった。一方、実行時は人物の情報を一つの正条件へまとめている。この構成で描き分けが崩れたため、二人の品質要件は未達とした。人数の語句だけを足す対処で完了にせず、人物別の条件と配置の設計を見直して実画像で再検証する必要がある。領域指定と人物同一性の保証は区別する。
