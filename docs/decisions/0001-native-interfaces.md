# ADR 0001: 標準APIとCLIを接続境界にする

状態: 採用済み

## 背景

CLI、標準画面、将来の別インターフェースから同じ生成・保存を利用し、GPUサービスを変更しても作品の管理を共用する必要があります。

## 決定

ComfyUI標準APIと公式Colab CLIを再利用します。domainは契約、applicationは生成・回収・終了の判断、infrastructureは通信・保存・プロバイダー・セッション調整、interfacesはCLIとComfyUIのHTTP・画面拡張、gpuは一時環境の導入・起動を担当します。

標準グラフをデータとして配布し、独自の計算ノードやグラフ言語を作りません。作業フォルダーのセットは同梱版と同じ形式で扱い、起動時に検証・固定します。

## 結果と制約

起動済みComfyUIへの接続は標準APIで利用できます。追加モデル準備と素材保全には同じ拡張が必要です。公式Colab CLIの内部SSH関数への依存は固定版のアダプターへ限定し、契約テストと実機検証で確認します。

DB・独自GUI・APIの実装はありません。交換が必要な境界の契約を保ち、将来機能のためだけの汎用層は追加しません。
