# 同行する会話と検証生成物の保持

確認日: 2026-11-06（日本時間）。対象はREQ-CONVERSATION-CONTINUITY、REQ-PLAYER-ACTIONS、REQ-REAL-ACCEPTANCE、REQ-VERIFICATION-RETENTION。

## 達成状況

現在地の共有、自然文の移動と返答の同時保存、再開時の重複防止、操作の簡素化、検証生成物の保持は実装済み。実4Bモデルで20ターンを保存し、最終返答を修正後の分岐で再生成した。再読込と全件の順序、通常・狭い・短い画面の表示を確認した。

確認したJSON断片の混入は再生成で解消した。一方、4Bの要約には予定の場所や準備状況を補う傾向が残る。保存・表示の成功を任意の入力に対する意味の正確さの保証とは扱わない。T4の追加受入も未実施であり、全要件の受入完了ではない。

## 原因と修正

- 人物別の現在地と同行判断が、同じ場面の会話を表示しない原因になっていた。現在地を一つにし、画像、履歴、公開契約、操作を揃えた。人物別の服装と持ち物は維持する。
- 移動と質問の同時入力を返答の種類で分類すると、通常の台詞に分類されて移動が落ちた。即時移動の判定を独立した必須項目へ分離した。保存した解釈から移動を一度だけ確定し、移動後の返答まで同じ操作・ターンへ保存する。
- 応答項目の説明はスキーマに含まれていたが、同じ定義が会話指示へ展開されていなかった。移動、持ち物、動作、台詞の説明を同じ定義から指示のresponse_rulesにも渡す。形式制約と意味の指示を混同しない。
- 古い実行一覧の再取得が、個別取得済みの完了状態を実行中へ戻していた。同じQueryキャッシュの終端状態を維持し、送信待ちのままになる回帰を追加した。
- 行動検証の確認項目の失敗が終了コードへ反映されず、保存済み結果の検査も不十分だった。終端状態、全項目、入力不変、後始末を判定し、操作IDと検査項目を保存する。新規・保存済みへ同じ検査を適用し、期限後の確認は追加送信できない読取専用にする。
- 成功時のトレース、隔離DB、検証環境の世代が増え続けていた。pytest・Playwright・Nodeの標準保持とteardownを使い、成功時のDBはサーバー終了後に整理する。使用リースで環境を保護し、使用中・作成中・所有不明・リンク先を削除しない。

設計と操作は[現在地と行動](../../current/player-actions.md)、[保存](../../current/storage.md)、[整理手順](../../operations/storage-cleanup.md)、[設計判断](../../decisions/0023-shared-location-and-verification-retention.md)を参照。

## 実LLMと画面

自然文の移動と合言葉を同時に含む日本語の反例は、修正前には移動漏れと持ち物の誤追加が再現した。項目の指示を実際のメッセージへ渡した後は、移動の一回性、共有する移動先、可視の返答、合言葉が持ち物にならないことを通過した。

新規の日本語長会話は、最初の1ターンで古書店員が本を手に取った。持ち物を全ターン禁止していた検査が通常の物理動作まで拒否したため、原記録を保持して検査条件を訂正した。情報として登場する合言葉が物体へ変わらないことを検査し、同じ保存済み1ターンから19ターンを追加した。最初の送信は繰り返していない。

20ターンでは、名前への回答、自然文の移動と質問、条件付き発言での現在地維持、明示移動と発言、合言葉、土曜日と午後4時への訂正、人物と現在地、再読込後の全件の順序を通過した。英語の短い検証でも、明示移動と返答、人物別の服装、合言葉、物体化の防止を通過した。

20ターン目の手動確認では末尾にJSON断片があった。原応答と保存本文のハッシュが一致したため、保存破損ではなく生成内容の不良と判断した。最初の自動成功を品質の成功へ読み替えず、不合格の追加評価を保存した。台詞と応答JSONの境界を項目の指示へ明記し、固定した非技術会話の検査にも観測済みの断片を追加した。本文から記号を削る後処理は追加していない。

修正後の読取専用検査は、元の20ターン目を同じ操作IDのreply_content不合格として検出した。追加推論は0回だった。その後、別の許可枠で19ターン目から新規分岐し、最後の1ターンを1呼び出しで生成した。混入はなく、原応答と保存本文の一致、前半19ターンの不変、元の不合格原本の保持を確認した。全20件の再検査、表示、再読込、順序も通過した。これは最終版で新規20ターンを最初から生成した結果ではない。

分岐した保存済み会話は1440×960、390×844、390×420で確認した。横方向のはみ出し、会話欠落、入力のフォーカス境界の欠けは検出しなかった。短い画面でも行き先の下書きと送信が見える。想定外のブラウザー例外・通信失敗は0件だった。物理端末のIME・ソフトウェアキーボードは未確認。

最終要約はJSON混入の検査を通過したが、集合場所を現在地に寄せて詳しくし、タオルの準備を完了済みとして語った。意味の忠実さには改善余地があり、この固定ケースの合格を任意の入力へ一般化しない。
