# 構成と設定

## 実行経路

WindowsのCLIから共有SSH接続を通して、Colab上のComfyUI標準APIを呼び出します。WindowsとComfyUIの待ち受けはループバックに限定します。
公式Colab CLIがGoogle認証、ランタイムの確保、ファイル転送、SSHのWebSocket接続を担当します。外部ComfyUIには標準APIで直接接続します。

CLIはTyper、設定と保存データはPydantic、通信はHTTPX、排他制御はfilelock、画像検証はPillowを使用します。
モデル取得はhuggingface_hub、資格情報はkeyring、子プロセスの終了はpsutilを使用します。

## 責務と依存関係

- CLI：入力、表示、終了コード。
- 接続の管理：監視、終了待ち、回収とGPU終了の順序。
- Colab制御：公式CLI、所有IDの照合、転送、SSH、GPU終了確認。
- GPU側の処理：固定した実行環境、モデル、ComfyUIの準備。
- 生成と保存：要求の記録、キューと履歴の照合、画像取得、原子的保存。

生成と保存からColab制御へは依存しません。通常終了と監視停止後の終了は同じ処理を使用します。

## 要求と終了の管理

CLIは送信前に要求を保存し、実行IDをComfyUIのextra_dataへ渡します。画面の要求は接続IDとComfyUIの生成IDから一意に識別します。
キューと完了履歴を読み、記録・回収・未完了判定を行います。画像取得に失敗した要求は再試行でき、ほかの要求の回収を妨げません。
画像とJSONは同じフォルダーの一時ファイルから置き換えます。要求と回収結果の状態更新には同じロックを使用します。

Colabの終了は、回収、ログ取得、GPU終了確認、ローカル接続の終了、履歴の確定、所有記録の削除の順に進めます。
終了を確認したGPUに未回収要求があればlostへ変更します。終了や後始末を確認できない場合は所有記録を保持します。

公式CLIの設定はプロジェクトごとに分離します。SSHには自動確保の経路があるため、所有IDとセッションの存在をロック下で照合します。
ホスト鍵はランタイムごとに記録し、再接続で照合します。

外部接続では、開始前のキューと履歴を取り込みません。専用の識別ファイルは要求せず、確認できないソース・モデル情報はnullで保存します。
標準APIだけでは同じURLの外部サーバーの入れ替わりを完全に識別できません。

## ソースと依存関係

HEADのGitアーカイブを転送し、SHA256を照合して展開します。モデル、作業ツリー、Git履歴、資格情報は転送しません。
ComfyUIとフロントエンドは配布設定、Pythonは.python-version、依存関係はuv.lockで固定します。
ローカルの公式CLI依存はcolab-client、GPU依存はworkerに分離しています。

モデルはローカルとGPUが配布元から直接取得し、同じSHA256を検証します。Colab内のモデルはランタイムが存続する間だけ再利用します。
画面とAPI用のワークフローJSONを同梱し、接続と生成条件の一致をテストします。入力画面とノード画面はComfyUIの標準テンプレートです。

## 設定

komaquill.tomlと`KOMAQUILL_項目名`の環境変数を使います。環境変数が優先されます。

| 項目 | 既定値 | 用途 |
|---|---:|---|
| gpu | T4 | 新規に確保するGPU |
| local_port | 18188 | Windows側の接続ポート |
| remote_port | 8188 | GPU側のComfyUIポート |
| poll_interval | 2秒 | 監視の間隔 |
| request_timeout | 30秒 | API通信 |
| preparation_timeout | 900秒 | 環境とComfyUIの準備 |
| generation_timeout | 600秒 | generateの待機 |
| shutdown_timeout | 600秒 | 終了前の生成待機 |
| control_timeout | 90秒 | 公式CLI、SSH、最終ログ取得 |
| execution_timeout | 86400秒 | GPU側のComfyUI実行上限 |

## 保存と認証

保存先は作業フォルダー内の`.artifacts/`です。画像、モデル、履歴、ログ、環境、キャッシュ、SSH鍵を保存し、Gitと配布物から除外します。
Google認証と公式CLIの管理ファイルは`~/.config/colab-cli/`に保存します。外部接続のパスワードはOSの資格情報ストアを使います。

公式CLIの詳細ログと例外の変数表示は無効にします。診断には発生時刻、操作、ランタイムID、例外種別、HTTPステータス、コードの位置だけを保存します。
