# Klein 4B・9Bの比較

## 対象と目的

固定した原文・場面仕様・演出条件から、Kleinの二つの構成を比較する。計画LLMの変更と複数場面の連続生成は対象外とする。既存8題材の構造検証は維持する。

## 準備

[比較設定](../../tests/fixtures/klein-comparison/config.toml)を確定し、必要な資源の固定版・利用条件・SHA256と空き容量を確認する。認証をGPUへ転送しない。モデル原本は共有し、検証用のコピーを増やさない。

全要求をGPU確保前に関連付ける。原文の必須条件と、追加した外見・構図の条件へ識別子と由来を付ける。再開では確定済みの条件、seed、使用済み予算を引き継ぐ。

原文と照合した場面仕様は[仕様データ](../../tests/fixtures/klein-comparison/specifications.json)へ置き、物語別の生成分岐を検証補助へ追加しない。Fake応答の構造検証とは別の入力として扱う。

検証補助は`python -m tests.live.klein_comparison`で実行する。`prepare REPORT --source PARENTS_WORKSPACE --parents PARENTS_JSON`で計画・全要求・親画像を固定する。親のJSONは場面位置、保存キー、SHA256、元の編集文と可視状態を中心にした編集文を持つ。原文・親画像・指示は非公開の作業データへ保存する。

`start REPORT --source MODELS_WORKSPACE --gpu T4`で回帰確認用の資源だけを共有し、`generate REPORT --group regression`で実行する。終了後、同じREPORTへ`start --gpu A100`を実行し、`baseline`・`edit`・`ablation`をモデル別に処理する。終了は`stop REPORT`を使う。終了操作は検証対象のコードが変わっていても利用できる。

標準画面へ渡す要求は`export-ui REPORT --job JOB --view app`または`--view graph`で予約し、出力した標準JSONを読み込む。実行後の`adopt-ui`は保存された実行グラフと素材ハッシュが一致する一件だけを対応付ける。受付が不明なら再送せず、既存の履歴を回収する。CLIの確認でも同じ確定入力を使い、追加の画像枠を設けない。

## 実施と評価

T4で4Bの生成・編集を回帰確認し、同じA100で4B・9Bを比較する。CLI/APIとApp Mode/Node Graphは同じ予算内で確認する。転送の見積もりが期限に収まらない場合は通常終了し、未実施と理由を残す。

原文一致、対象数、所有者、小物の状態、身体、外見、連続性、編集後の条件保持を実画像で評価する。評価者、モデル、指示ハッシュ、条件ID、根拠を保持する。選択は画質合格と分け、判断不能では既存の有効選択か生成順を使う。

同じ親画像で二種類の編集文を比較し、対象外の必須条件も再評価する。LoRAを両方外した比較は生成構成への寄与として扱い、個々のLoRAへ原因を帰属しない。

## 記録と完了

対象版・内容ハッシュ、実効dtype、初回ロード、ウォーム状態、キュー、転送、回収、CU、GPU終了を分けて記録する。保存成功数、作品合格数、勝ち・引分け・負け・判断不能を分母付きで報告する。

実装、累積検証、実機、画質、原因解決は別々に判定する。実機未実施と未解決の原因を成功へ昇格させない。GPU停止・所有解放を確認した後に、最小証拠とノウハウを残して再作成可能なデータを整理する。

結果は対象版が固定された時点で追記する。過去の成功を今回の実機結果として扱わない。

ブラウザーから初めて観測したRunのcreated_atは、送信時刻ではない。この時刻からキュー待ち時間を推測せず不明とする。送信記録がある場合も、時刻の前後関係を確認する。原時刻は変更しない。初回生成の時間にはロードが含まれ、モデルロードだけの時間やGPU計算だけの時間へ分離できない場合は未測定とする。

送信・画面用JSONの作成・起動は確定時の実装と検証補助へ固定する。保存済み結果の読み取りと評価訂正は新しい読取版でも行い、生成した版と読取版を分けて記録する。

`reviews REPORT --review-file FILE`で実画像の評価を追記し、`summarize REPORT`で有効画像、採否、比較の選好、未実施を集計する。全場面の有効画像が揃った組だけを組版する。欠けた画像を仮画像で補わず、未評価や判断不能を合格へ変更しない。

[実機記録](results/2026-10-27-klein-switching.md)では、保存できた回帰画像と、転送期限により未実施となった比較を分けて扱う。
