# 目的と範囲

## 利用者の目的

ストーリーから本文付き画像を順次生成し、標準画面で細部を編集しながら、作品と再現に必要な条件・素材をPCへ残します。通常の生成ではGPU側の接続先や転送先を指定せずに利用できます。

## 現在の提供範囲

Python CLI、ComfyUI標準API・App Mode・Node Graph、公式Colab CLIを組み合わせます。起動時に選択したColab GPUまたは起動済みComfyUIへ接続し、プリセット、モデル準備、生成・回収、入力・保存ワークフローの保全を扱います。

作品、生成条件、入力素材、モデル台帳の正本は作業フォルダーの.artifacts/dataです。画像生成用のモデル本体は外部GPUへ直接取得し、一時キャッシュとして扱います。Driveへ永続保存しません。通常の品質ゲートではGPUを確保しません。

## 制約

一つの作業フォルダーで一つのセッションを管理します。GPUの新規確保は明示的なstartだけです。PCの電源断やログアウトでGPUが停止する保証はありません。未保存の画面編集、拡張ノード独自のファイル、動画・音声は保存の対象外です。登録済みモデルは、利用条件への同意と認証を利用者が済ませた後に確認して取得します。未知のモデルや追加ノードを自動導入しません。

## ストーリーと公開API

日本語ストーリーから描画しやすい場面と本文を計画し、起動済みセッションで画像を順次保存できます。枚数は自動選択が既定で、固定枚数も指定できます。CLIとPythonのClientは同じ計画・生成・再開・保存処理を使います。長編の分割計画や複数プロンプト入力の候補は[今後の候補](../plans/future.md)で管理します。

## 用語

| 用語 | 意味 |
|---|---|
| 作業フォルダー | komaquill.tomlと.artifactsを置く利用単位。Gitは必須ではない |
| 生成セット | 生成条件、画面グラフ、APIグラフ、入力対応の一式 |
| モデル | modelで選ぶ画像生成モデル。起動時のmodelsで利用対象を確定する |
| 操作 | generateまたはedit。モデルと操作から対応する生成セットを解決する |
| LLMプロファイル | 接続先、モデル、認証の参照を持つ計画用設定 |
| 計画 | 原文、人物共通設定、順序付き本文と描く瞬間の不変の記録 |
| 生成試行 | 一つの計画を固定した画像設定で生成する単位 |
| 資源 | 拡散モデル、テキストエンコーダー、VAE、LoRA、checkpointの定義と取得ファイル |
| 回収 | GPU側の結果を検証し、PCへ保存して履歴を確定する処理 |
| 素材 | 入力画像・マスクと、明示的にSaveしたワークフロー |
