# 保存物の扱い

| フォルダー | 内容 | 削除 |
|---|---|---|
| data | 作品、モデル、履歴、入力、ワークフロー | 削除しない |
| records | ログ、検査、移行、削除の記録 | 削除しない |
| state | 所有、接続、復旧の状態 | 手動削除せずstopで終了する |
| runtime | Python、uv、環境、転送物 | 通常のcleanでは削除しない |
| cache | 再作成可能なキャッシュ | cleanで使用状況を確認する |
| tmp | 一時データ | cleanで所有と未使用を確認する |
| dist | 配布物 | 最新成功の参照先を残す |

`komaquill clean --dry-run`で対象を確認し、`komaquill clean`で適格なものだけ整理します。使用中・用途不明のファイルは残します。ログと検査記録は削除しません。

再作成できる環境でも、使用中に消すと操作を続けられません。このフォルダー全体をまとめて削除しないでください。バックアップではdataと必要なrecordsを保全してください。
