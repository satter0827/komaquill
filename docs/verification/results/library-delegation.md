## 検査中に確認した問題

Client内の設定共有と、新しい起動での設定再解決を分離した。保存済み作品の閲覧、画像回収、GPU終了がLLMの設定検証へ依存しないことも確認した。

同じ画像操作で複数の文章を英訳すると呼び出し記録が上書きされる経路を修正した。操作・呼び出し・修正を区別し、既知分の使用量を失わないようにした。

axeで検出した文字色のコントラスト、カードの読み上げ名、設定内の見出し階層を共通部品へ反映した。拡大相当の短い表示領域では、会話の最小高さによって入力欄が押し出されていた。会話領域の高さを縮め、履歴をキーボードでスクロールできるようにした。

CSS zoomだけを変えた観測には、広い画面の配置が残る差と判定不能があった。元の観測は保持し、合格へ書き換えていない。拡大表示の回帰検査は、半分のCSS表示幅と倍の描画倍率を固定する標準機能へ改めた。画像、読み上げ名、入力欄の表示、履歴のスクロール、詳細を閉じた後のフォーカスを合わせて確認する。
