# 使い方と障害対応

## 接続する

`komaquill start` でモデルを確認し、Gitコミットで固定したノートブックを開きます。
そのコミットをGitHubへ送信してから使用してください。Colab Pro等の有料プランと計算ユニット残高が必要です。
GoogleログインとGPUの割り当てはColabで行います。新しいリビジョンは新しいランタイムで起動します。

左側の鍵アイコンから `KOMAQUILL_PASSWORD` を20文字以上で登録し、ノートブックからのアクセスを許可します。
値はノートブックやチャットへ書かず、Colab Secretsに保存してください。
起動セルに表示された接続先URLをローカルへ入力します。URLが分かっている場合は
`komaquill start --endpoint https://接続先.trycloudflare.com` で再設定できます。

GoogleログインとComfyUIの認証は別です。ブラウザーのComfyUI認証にはユーザー名 `komaquill` を使用します。
CLIのパスワードはWindowsの資格情報ストアに保存します。設定JSONには保存しません。

## 生成と保存

`komaquill generate --prompt "a small cabin" --negative "text, watermark" --seed 42` で条件を指定します。
プロンプトを省略すると入力を求めます。日本語の文字列も保存できますが、初期モデルへの画像説明には英語を推奨します。
日本語ストーリーの翻訳・分割は初期版には含みません。

`komaquill open --view app` は入力画面、`--view graph` はノード画面を開きます。
CLIを起動している間、完了した生成結果を2秒間隔で確認して回収します。
App Builderで入力欄を変更できます。画面から作成した保存用ワークフローは、必要に応じてJSONをダウンロードしてください。
実際に生成したときのワークフローは画像と一緒に自動保存します。

`artifacts/runs/実行ID/` に `run.json`、実行用JSON、画面用JSON、`images/` を保存します。
画像の内容を検証してから一時ファイルを置き換え、全画像の保存後に保存完了を記録します。
遠隔のファイル名をローカルパスへ流用しません。

## 切断と終了

一時的な切断では画面利用中のCLIが再接続を待ちます。トンネルのURLが変わった場合はCtrl+Cで終了し、startで再接続してください。
`komaquill collect` で同じランタイムに残っている完了結果を回収します。
特定の要求は `komaquill collect 実行ID` で照合できます。送信結果が不明なときにgenerateを再実行すると別の生成になるため、先に回収してください。

Colabのランタイムが削除されると未回収の画像と履歴は失われます。Google Driveにコピーを保持する機能はありません。
回収状況を確認し、Colabの「ランタイムを接続解除して削除」を実行して終了します。

## 接続できない場合

1. ColabにGPUが割り当てられているか確認します。
2. 起動セルのエラーと、Colab側の `artifacts/runtime/` にあるログを確認します。
3. 接続先URLとパスワードをstartで設定し直します。
4. doctorでGPU、モデル、標準ノードを確認します。

Quick Tunnelには稼働保証がなく、再起動するとURLが変わります。常設サーバーとしては使用しません。
公式Colab CLIは現在Windows非対応のため、Windowsからの起動にはColabノートブックを使用します。

## ローカルの保存場所

設定ファイルのある作業フォルダー配下に集約します。別のフォルダーから使う場合は `--project 作業フォルダー` を指定できます。
OneDrive配下に配置した場合、`.gitignore` はOneDriveの同期を止めません。モデル等を同期したくない場合は同期設定を別途調整してください。
