# 会話画面を使う

## 開発環境で起動する

Windowsでは`bootstrap/setup.ps1`でPython環境を導入し、ルートで`pnpm install`を実行します。次に起動します。

```powershell
pnpm dev
```

表示されたViteのローカルURLを開きます。Reactの開発サーバーがHTTP APIへプロキシします。起動によるGPUの確保や実モデルへの送信はありません。

`New conversation`からタイトル、場面、人物、自分の役割、応答方針を入力します。人物と画像は省略できます。`fake`は固定サンプルです。`Hello`を送ると、応答と状態が保存され、再読込後も復元されます。`Edit state`では文字列の値を持つJSONオブジェクトを保存できます。編集中に別操作が状態を変えた場合は更新を拒否します。編集を閉じて現在状態を確認してから開き直してください。

任意の文章を送る場合は実モデルのプロファイルを選びます。接続先とモデル名は作業設定の`llm_profiles`で指定し、認証には環境変数名またはOS資格情報ストアの参照名を使います。送信前に、その要求と必要な修正呼び出しを許可するチェックを入れます。

## 配布版を起動する

```powershell
pnpm build
$wheel = (Get-ChildItem .artifacts/dist/komaquill-*-py3-none-any.whl).FullName
pip install "$wheel[web,llm]"
komaquill init C:/work/my-conversation
komaquill --project C:/work/my-conversation web --open
```

配布版にはReactが同梱されています。サーバーはこのPCからのみ利用できます。`--open`を省略するとブラウザーは開きません。

## 画像と実行環境を使う

`Images`は会話を作らずに画像を生成する画面です。接続中のComfyUIへ送信し、保存済み候補を表示します。通信や回収に失敗した場合は同じ要求の回収を再実行します。受付不明の要求を再送しないでください。

`Runtime`では既存ComfyUIへの接続、状態の確認、所有している実行環境の停止を行います。Colabを新たに確保する場合はCLIで明示的に`start`を実行し、必要な対話認証を端末で完了させます。標準のApp ModeとNode Graphへの入口はこの画面とCLIの`open`で使用できます。外部ComfyUIでは画面から標準ワークフローをダウンロードして読み込みます。

ブラウザーを閉じてもGPUは停止しません。作業終了時は停止操作でプロバイダーの終了結果を確認します。外部ComfyUIへの接続を終了しても、そのサーバーは停止しません。

## 中断から復旧する

画面を再読込すると保存済み会話が復元されます。別の送信が実行中の場合は完了を待ちます。サーバー停止後は検証済み応答のチェックポイントから本文を復旧します。応答を確認できない要求は受付不明として保持し、自動再送しません。通信失敗後の再試行は画面の同じ要求のボタンを使います。ストレージの障害は保存先を復旧してサーバーを再起動し、既存操作の状態を取得してください。

保存先と依存関係は[現在の設計](../current/web.md)、検証コマンドは[開発手順](../development/workflow.md)を参照してください。
