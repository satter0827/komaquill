# 設定・LLM実行・API取得と検査の分担

## 設定の解決と有効期間

設定の合成は[WorkspaceConfiguration](../../src/backend/src/komaquill/adapters/configuration.py)の公開sourceへ集める。明示入力、環境変数、作業設定、同梱既定値の順に優先し、入れ子は指定した項目だけを更新する。未指定と空・偽・ゼロを区別する。dotenvや秘密ファイルは暗黙に読み込まない。

Client内で初めて設定を必要とする時点に、ファイルと環境変数を一度読み取る。長時間動くアプリケーションはconfigureで起動時に確定する。用途別の検証は必要になった時点で行い、画像処理、接続、会話、下書き、記憶作成、英訳へ同じ読込結果を共有する。新しいClientでの起動は設定を再解決する。保存済み作品の閲覧はLLM設定を必要としない。画像の回収とGPU終了は保存済みセッションの設定を使い、LLMの検証と排他から分離する。

## 共通実行と機能別処理

[StructuredExecution](../../src/backend/src/komaquill/adapters/llm/execution.py)は接続、認証、モデル照合、SDK実行、有限修正、原応答と使用量の記録を担当する。会話、下書き、英訳、記憶作成はそれぞれの入力・指示・結果変換を担当し、組み立て時に狭い役割を注入する。具象Responderの取り出しや英訳用の再生成は行わない。

LangGraphは会話入力の固定と、共通の要求・検証・有限修正を扱う。公式SqliteSaverを同じSQLiteファイルで使用し、受信済みの原応答と検証済み結果を再利用する。[実行とコンテンツの契約](execution-and-content.md)を正本とする。公開bindでJSON Schemaを渡し、Pydanticで型変換を許さず検証する。拒否、打ち切り、モデル不一致、通信失敗は再送しない。構文と意味の修正は設定された有限回数に限り、前の原応答を標準メッセージとして渡す。外部トレースとSDKの自動再試行を無効にし、実LLMの呼び出しには操作ごとの許可を必要とする。

プリセットの内容変更、画像入力の変更、生成方針の判断は[libraryの純粋な処理](../../src/backend/src/komaquill/library/rendering.py)で行う。保存アダプターは判断結果を同じ短いトランザクションで保存・受付・関連付けへ反映し、通信をその中へ持ち込まない。

## 文脈・記憶・使用量

[ContextBudget](../../src/backend/src/komaquill/adapters/llm/context.py)は送信前の計数と独立した文字数の安全上限を適用する。LM Studioでは公式SDKで読込済みモデルの文脈上限とテンプレートを取得して計数し、モデルを自動ロードしない。他の接続では保守的な概算を使う。文法制約のスキーマをモデルの入力へ含める接続かどうかを設定で区別する。修正時は前応答も再計算する。プロバイダーが返す使用量とは分けて記録する。上限と接続設定は[会話設定](../../src/backend/src/komaquill/resources/conversations/defaults.toml)を正本とする。

必須情報と最新入力が収まらない場合は、追加要求を送らず型付き失敗を返す。履歴は完全なターン単位で扱い、予算に収まる限り記憶作成を呼ばない。超過した場合だけ古い確定履歴から原文を選択し、ターンID・項目・範囲・内容ハッシュとともに保存する。引用を元の記録と照合し、要約の再執筆による否定や創作を防ぐ。直近の完全な履歴を残し、設定された処理上限で収まらなければ失敗を返す。既存の本文、状態、保存ハッシュを変更しない。判断は[原文を根拠にした会話](../decisions/0018-source-backed-conversation.md)を参照する。

呼び出し別の記録を正本とし、既知の使用量をadd_usageで合算する。記憶作成、修正、英訳を含め、総呼び出し数、既知件数、不明件数、既知分の合計、全量が既知かを別に保存する。集計の再作成で呼び出しを二重計上しない。保存先は[成果物の管理](../operations/artifacts.md)を参照する。実LLMでの品質維持と総量削減は別の受入検証とする。

## 画面の取得・更新と操作監視

[生成設定](../../scripts/contracts.mjs)はOpenAPIからSDKとTanStack QueryのqueryOptions・mutationOptions・query keyを作る。取得、キャッシュ反映、無効化は同じ生成keyを使う。複数APIを組み合わせる保存・回収などの処理は機能側へ残す。

[操作監視](../../src/frontend/src/features/operations.ts)は操作取得、回収、終端判定、監視終了を共有する。遅れた応答で終端や既知の画像参照を後退させない。編集中の入力、保存版、受付済み操作、画像進捗を分ける。受付不明では操作IDと入力を保持して同じ操作を確認し、再取得や再マウントで生成を開始しない。保存の確定はPythonが行う。

会話や描画の受付応答が失われた場合は、同じ操作IDを取得して確認する。取得で受付済みと判明した操作は通常の受付結果と同じ経路へ反映し、編集を続けている次の入力は保持する。確認できるまでは自動再送せず、明示した再確認も同じIDと入力を使う。

会話の入力は送信時の編集回数と対応付ける。受付時に送信後の編集がなければ入力を空にし、同じ文章を打ち直した場合も含め、編集があれば次の入力として保持する。

## 文書とアクセシビリティの検査

[文書検査](../../scripts/checks/documentation.py)はmarkdown-it-pyのCommonMarkトークンからリンク、画像、見出しを抽出する。コードを参照と誤認せず、参照形式、括弧、装飾、Setext見出しを扱う。パスの復号と作業領域内の存在、GitHub形式の重複アンカー、要件の参照は既存の検査で確認する。

[Playwrightのfixture](../../tests/e2e/web/fixtures.ts)はaxeでWCAG 2.1 A・AAの適用可能なルールを検査する。日英の主要画面、入力・通信エラー、確認操作、キーボード、フォーカス復帰、拡大、狭い画面を対象とする。違反と判定不能を別に保存し、判定不能は確認待ちとして残す。自動検査を全面的なアクセシビリティ適合の保証へ広げない。markdown-it-pyとaxeは開発依存に限定し、製品とGPU用環境へ追加しない。

ブラウザー検証のJSON記録は[保存処理](../../scripts/web/evidence.mjs)からatomicallyへ委ねる。同じパスへの書き込みの直列化、一時ファイルからの原子的置換、Windowsの一時的なロックへの有限再試行をライブラリーで扱う。保存完了を待ってから次へ進み、恒久的な失敗を成功へ変換しない。検証専用の依存とし、製品やGPUへ追加しない。

移行データの保全を確認するテストは、停止済みDBの共通fixtureを明示してホストのプロセス状態から分離する。全テストへ自動適用せず、ファイル使用中・不明・監視中の拒否は実際の停止判定を使う別のテストで確認する。製品の安全な停止条件をテスト都合で緩めない。

拡大表示の回帰検査はPlaywright標準のviewportとdeviceScaleFactorを使い、表示幅を半分、描画倍率を倍にした条件で行う。会話領域は高さを縮められるようにし、入力欄を表示領域に残す。履歴には読み上げ名を持つlogとキーボードのフォーカスを設定し、短い表示領域でもスクロールできるようにする。

会話と英訳の応答言語は、入力指示とスキーマへ明示する。言語不一致を型不正と区別して記録し、元の応答を保持して有限回数だけ修正する。記憶の引用は原文の言語を維持し、翻訳や自由文の再要約を行わない。

直近の履歴を保持する件数に達しても、文脈予算内なら古い履歴を残して応答する。必須入力と直近の完全な履歴だけで予算を超える場合は、記憶作成の追加要求より先に停止する。

## ローカルモデルの再接続

LM Studioのトークン計数では、公開SDKの読み取りセッションを計数ごとに閉じる。モデルの読込済み一覧から指定モデルだけを選び、文脈上限は新しい予算を作る時点で取得する。アプリ全体へWebSocketクライアントやモデルのハンドルを保持しない。モデルを停止・再読込した後も、古いSDKセッションを次の操作へ持ち越さない。

この接続はテンプレートとトークン計数に限る。モデルの自動読込、推論の自動再送、別モデルへの切替は追加しない。SDKの失敗は従来の安全な型付きエラーへ変換する。
