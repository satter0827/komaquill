# 会話画面の使い方

## 起動

開発環境のPython依存は `bootstrap/setup.ps1`、Node依存は `node bootstrap/setup-node.mjs` で準備する。既存DBを使う場合は、アプリと監視を停止して `komaquill migrate` を実行する。移行前の内容は `.artifacts/records/migrations` に保存される。

開発時は `pnpm dev` を実行し、Viteが案内するローカルURLを開く。APIと画面は別のポートで動く。`pnpm build` で作成したwheelを導入した環境では、`komaquill --project 作業場所 web` を実行して案内されたURLを開く。ブラウザーを自動で開く場合だけ `--open` を付ける。

## 作って遊ぶ

1. 「あなた」で、物語の中で使う名前・呼ばれ方・外見・立場を保存する。複数作成し、普段使うものを既定にできる。
2. 「キャラクター」で会話する相手を作る。性格、話し方、背景、自分との関係を保存できる。
3. 「ストーリー」で舞台、導入、最初の場所、当面の目的とおすすめの相手を保存する。
4. 「物語を始める」で、自分・相手1人・ストーリーを選んで開始する。選択中に作成画面へ移動した場合は、保存後に選択画面へ戻る。
5. 会話を送り、「遊ぶ」の「続きから」で保存済みの会話を開く。後からプリセットを編集・削除しても、開始した会話の設定と画像は保持される。

最初はサンプルの組と挨拶で試せる。任意の人物や会話を使う場合はローカルモデルを選び、操作ごとの利用を許可する。手元のモデルIDと接続先を変更する場合は [接続設定](../../src/backend/src/komaquill/resources/conversations/defaults.toml) を作業設定で上書きする。別モデルへ自動では切り替わらない。

ストーリーの「これを使う」から始めると、おすすめの相手が選ばれる。別の相手へ変更することもできる。ホームで保存内容を読み込めない場合は、表示された説明を確認して一覧を更新する。

## 下書きと画像

キャラクター・ストーリーの「下書きを作る」では短いアイデアから下書きを生成し、内容を確認してから保存する。生成にはローカルモデルの明示的な選択と許可が必要。

接続済みの画像サーバーがある場合は、保存後に人物画像やバナーを生成する。画像を作れなくても本文は保存される。日本語から画像を作る場合は、英訳に使うローカルモデルを選んで許可する。接続がない場合は設定の画像接続で準備し、保存済みの設定から画像を作る。所有GPUの新規確保はCLIの `start` で明示的に行う。

単発画像は「画像」から作成する。生成中に以前の画像がある場合はその画像を表示する。画像の受け取りに失敗した場合は回収を再実行し、受付が不明な要求は新しい操作として送らず、同じ要求を確認する。

## 表示と生成の好み

「設定」で日本語・英語、文字サイズ、表示の間隔、返事の長さ、画像を作る頻度を保存する。言語と返事の長さは次の操作へ適用し、保存済みの作品名や本文を自動翻訳しない。会話の途中でも、次の返事から言語を変えられる。

人物画像と状況は会話の補助欄に表示する。狭い画面では右上のボタンで開閉する。状態の直接編集や版は「物語の詳細」から確認する。
