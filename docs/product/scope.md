# 目的と範囲

製品コードはsrcにまとめ、React画面、Pythonの業務処理、API契約を分けます。現在の構成は[構成と設定](../current/architecture.md)、実装状態と受入条件は[要件台帳](../requirements/catalog.toml)を正本とします。未完了の項目は[統合計画](../plans/roleplay-chat.md)と個別の計画で管理します。

## 利用者の目的

物語の中の自分、会話する相手、舞台を保存して選び、会話と行動で物語を進めます。見たい場面を描き、設定・本文・画像・生成条件をPCへ残して続きを開けることを目指します。

## 現在の提供範囲

React画面から、自分1人のプロフィール、キャラクターとストーリーのプリセット、表示・生成の好みを保存できます。保存済みプリセットから会話を始め、日本語・英語で会話と場面説明を表示します。自分の移動・待機・身支度・目標は本人が確定し、送信ボタンの隣から現在の場面を描けます。人物画像とバナーは接続済みならプリセット保存後に生成し、画像に失敗しても本文を保持します。

HTTPとCLIは公開Python APIの同じ機能別サービスを呼びます。会話を使わない単発画像生成、ComfyUI標準API・App Mode・Node Graphも提供します。起動済みComfyUIへの接続、または公式Colab CLIによる明示的なGPU確保を利用し、モデル準備、生成・回収、入力素材と保存ワークフローの保全を扱います。

会話・プリセット・画像要求の構造化記録はSQLite、画像・生成条件・入力素材・モデル台帳の実体は作業フォルダーの.artifacts/dataへ保存します。ログ、検査結果、キャッシュ、依存環境、配布物も用途別に.artifactsへ集約します。画像生成用のモデル本体は外部GPUへ直接取得し、一時キャッシュとして扱います。Driveへ永続保存しません。通常の品質ゲートはFakeとlocalhostの擬似APIを使い、実LLMとGPUを呼びません。

## 制約

会話の相手は1人とし、一つの作業フォルダーで一つのGPU実行環境を管理します。GPUの新規確保は明示的なstartだけです。PCの電源断やログアウトでGPUが停止する保証はありません。未保存の画面編集、拡張ノード独自のファイル、動画・音声は保存の対象外です。登録済みモデルは、利用条件への同意と認証を利用者が済ませた後に確認して取得します。未知のモデルや追加ノードを自動導入しません。

## 生成品質と既存作品

保存・再開・画面操作の成功と、生成した本文や画像の品質を区別します。実モデルには行動の解釈、所有関係、現在の風景、要約後の想起、画像の年齢・性別・人数の反映で未達が残ります。実出力の確認範囲は[検証記録](../verification/README.md)を参照してください。顔の同一性や長編の自動完結を保証しません。

旧Storyの本文・計画・画像はarchiveから読み取り、既存作品を推測変換しません。新規の会話とプリセットは現在の公開APIを使います。長編の分割計画や複数プロンプト入力の候補は[今後の候補](../plans/future.md)で管理します。

## 用語

| 用語            | 意味                                                                        |
| --------------- | --------------------------------------------------------------------------- |
| 作業フォルダー  | komaquill.tomlと.artifactsを置く利用単位。Gitは必須ではない                 |
| 生成セット      | 生成条件、画面グラフ、APIグラフ、入力対応の一式                             |
| モデル          | modelで選ぶ画像生成モデル。起動時のmodelsで利用対象を確定する               |
| 操作            | generateまたはedit。モデルと操作から対応する生成セットを解決する            |
| 会話            | 開始時の定義、現在状態、確定した履歴を保持する物語                          |
| プリセット      | 会話開始時に選択するキャラクターやストーリーの保存設定                      |
| LLMプロファイル | 接続先、モデル、認証の参照を持つ生成用設定                                  |
| 生成操作        | 操作IDと受付時の入力を固定して会話や画像を生成する単位                      |
| 資源            | 拡散モデル、テキストエンコーダー、VAE、LoRA、checkpointの定義と取得ファイル |
| 回収            | GPU側の結果を検証し、PCへ保存して履歴を確定する処理                         |
| 素材            | 入力画像・マスクと、明示的にSaveしたワークフロー                            |
