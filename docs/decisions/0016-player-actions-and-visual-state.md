# 行動の確定と視覚情報の共有

状態: 採用。日付: 2026-11-02。

## 背景

保存した現在の服装と、外見の紹介文に残った開始時の服装が、画像説明へ同時に渡っていた。型と言語の検査は通っても、画像へ古い服装が戻る例があった。状態の直接編集には操作履歴がなく、LLMの変更案だけで自分の行動が確定する構成でもあった。

## 決定

自分の行動は型付きの操作として本人が確定する。自然文からの案、確定した行動、相手の反応を分ける。行動と返答受付を既存のSQLiteで一緒に保存し、返答の失敗では確定状態を戻さない。LangGraphは生成・検査・有限修正へ、LangMemは過去の履歴の要約へ引き続き限定する。

人物の身体的特徴と開始時の服装を分離し、画像には現在の視覚情報だけを渡す。旧文章を語句の置換で分割せず、曖昧なものは利用者の確認を必要とする。自由文の意味を保証する汎用判定器や常時の批評LLMは導入しない。

生成本文と画像説明で別々の現在場面を作ることを避け、背景表示を現在状態へ揃える。画像へ渡す構造化情報はPythonで組み立て、日本語の値だけをPydanticの必須フィールドでまとめて英訳する。英語の項目を再生成するLLM呼び出しは省く。キーの保持は検証できるが、翻訳の意味と画像モデルの指定遵守は別に評価する。

## 制約

自然文の行動抽出、翻訳の忠実さ、描写と状態の整合、WAIの指定遵守にはモデルの限界が残る。保存・権限・再開の機能検査と、実モデルの品質判定を分ける。顔を固定する追加工程、汎用のゲームルール言語、別の永続グラフ状態は今回追加しない。
