# 参照画像による編集の契約

`klein-4b-edit`はComfyUI標準のLoadImage、ImageScaleToTotalPixels、VAEEncode、ReferenceLatentを使用します。参照画像は新しい出力を導く入力です。変更対象外の画素保存や人物同一性は保証しません。

入力は公開APIのinputs.import_fileで読み取り、内容ハッシュで識別して保存します。参照画像とマスクの用途を混同せず、宣言されていない入力は送信前に拒否します。標準の編集セットはマスクを受け取りません。保存済みの入力を使って再開し、利用者の元ファイルを読み直しません。

RenderConfigは全場面の生成セット、入力、画像説明、対象別説明、宣言済みパラメーターを固定します。全場面を検証してから送信し、元の指定、適用済み入力、実行グラフの対応を保持します。

改善は通常の別Runです。親画像、修正指示、場面、入力ハッシュと条件を記録します。生成失敗と画像回収失敗を分け、公開済み出力を回収しても生成成功へ変更しません。受付不明の要求は既存IDで照合し、自動再送しません。

詳細は[操作](../guides/story-workflows.md)と[短編完成の検証](../verification/story-completion.md)を参照してください。
