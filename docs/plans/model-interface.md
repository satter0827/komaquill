## 原因を確認する問題

机の欠落、人数・所有者・小物の不一致は、原文、固定計画、変換入力、送信グラフ、画像の順に照合する。外見や衣服の変化、隠れた本の再出現は、共通外見と場面ごとの可視状態を分けて評価する。局所編集の合格を作品全体へ広げず、未評価条件を残す。

準備期限の超過は原因コードと初発理由を保存する。未作成ログは到達段階と取得履歴から必要性を判定する。隔離wheelの監視停止は保存・公開更新・通信・監視を切り分け、再実行成功だけでは解決扱いにしない。

Kleinの保存・評価・終了、モデル削除の実施結果と残る確認事項は[検証結果](../verification/results/model-interface.md)を参照してください。

準備期限と評価範囲の再レビュー、修正、残る確認は[再確認の結果](../verification/results/model-interface-review.md)を参照してください。
