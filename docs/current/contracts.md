# 状態とエラーの契約

この文書は実装済みの保存・失敗・終了の境界を説明します。フィールドと列挙値の正本は[domain](../../src/komaquill/domain/models.py)と[エラー定義](../../src/komaquill/domain/errors.py)です。

## 生成要求

CLIは送信前、標準画面は観測時に要求を記録します。受付不明の場合は再送せず、実行IDをキュー・履歴と照合します。画像の保存失敗は再回収できる状態へ残し、ほかの要求の回収を続けます。

savedは必要な画像と条件がローカルへ保存された状態です。failedは生成の失敗、lostは所有Colabの終了確認後に回収できなくなった状態です。外部接続の終了で要求をlostへ変更しません。

## 保存

画像ごとのSHA256・容量・寸法を保存時に計算します。状態更新と保存確定は短い共通ロックで保護します。通信はその外で行い、要求単位の排他と確定前の再読込みで競合を防ぎます。複数ファイルの一括原子性は仮定せず、チェックポイントから再開します。新しい履歴形式でも過去の画像・履歴・取得済みログを書き換えません。

送信前のAPI・画面グラフはsubmitted-workflow-api.json・submitted-workflow.json、サーバーで最初に観測したグラフはworkflow-api.json・workflow.jsonへ分けて保存します。参照画像を固定した後のパスを実行条件へ残し、Runのworkflow_sha256は保存した観測グラフと一致させます。観測前の分析用出力は実行グラフを不明とし、送信グラフで代用しません。

後続の観測でComfyUIのキャッシュ判定などのメタデータが増えても、保存した実行条件とハッシュを変更しません。ノード・種類・入力の不一致は受け入れず、保存済みRunを後退させません。観測グラフの保存後にRunの更新へ失敗した場合は、同じファイルから再開します。既存記録の条件やハッシュは移行・補完しません。

## 失敗

FailureInfoはエラーコード、発生元の処理段階、再試行可否、例外種別、必要な場合のHTTP状態を持ちます。明示された発生段階を上書きせず、呼び出し側の文脈はイベントへ記録します。本文・応答内容・認証情報・例外の変数は含めません。GPU起動進捗は最初の失敗を保持し、外側の処理で発生した汎用エラーや後続の成功通知で置き換えません。準備期限の超過は専用コードで記録します。製品の表示はmessages.jsonから英語で取得し、業務処理は表示文言に依存しません。

collectは正常分の保存後、今回回収できなかったIDを表示して非ゼロ終了します。statusは確認できない記録を不明とし、破損記録を空のキューとして扱いません。

## 終了

回収、最終ログ取得、GPU終了確認、ローカル接続終了、履歴確定、結果保存、所有記録削除の順に進みます。途中で失敗してもGPU終了を試み、未確認の結果と所有記録を残します。外部ComfyUIの停止はローカル監視の終了に限定します。

プロバイダーの観測、監視プロセス、SSH、HTTP接続は独立した事実です。一つが停止していることを、GPU終了の根拠にしません。


## ストーリー

[ストーリーの契約](stories.md)に入力、計画、生成試行、状態取得を定義します。原文・場面・生成IDを関連付け、画像の保存状態は既存のRunから導出します。計画の不変性と試行単位の排他を維持し、条件を変える場合は新しい試行を作ります。

閲覧用更新の成否はpublicationsとunpublished_idsへ保存し、画像回収やGPU終了と区別します。閲覧用更新だけが失敗した場合も、確認済みGPUの終了・接続の後始末・履歴確定・結果保存が済めば所有記録を解放します。失敗は終了結果と非ゼロ終了で報告します。

## 候補と補助画像

新しいRunはoutput_specへ主出力ノードと要求候補数を保持します。画像のmetadataには出力ノード、バッチ内位置、candidate・auxiliary・unknownの役割を記録します。バッチのseedと位置を保持し、独立した単画像のseedへ推測変換しません。

一部の画像を保存しても、必要な出力が揃うまで要求はqueuedです。既に保存した候補は閲覧でき、再回収で画像一覧を減らしません。主出力数が一致しない場合も検証できた画像を保持し、保存成功へ進めず再回収を案内します。

過去の履歴へ候補数と出力役割を補いません。旧入力と設定は保存時の版の読み取り専用契約で扱い、値・実行グラフ・保存済みハッシュを変更しません。旧契約を新規生成や自動再送へ使用しません。

CUとHigh RAMは新規設定の契約だけに含めます。旧設定へ現在の既定値を追加せず、規模の情報がないモデルへ推測した規模を保存しません。
