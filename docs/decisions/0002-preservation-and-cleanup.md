# ADR 0002: 保存物を保全要否で分ける

状態: 採用済み

## 背景

画像・モデル・履歴と、ログ・検証記録、環境・キャッシュが同じ階層にあると、何を削除できるか判断しにくくなります。生成物の移動では内容を保全し、停止と復旧にも必要な記録を残す必要があります。

## 決定

ローカルの.artifactsをdata、records、state、runtime、cache、tmp、distへ分類します。dataは作品と資源、recordsは実行・検証・移行・整理の証跡として保持します。stateとruntimeも通常のcleanから除外します。

cleanは停止確認とプレビューを行い、所有が分かる再作成可能データだけを整理します。uvキャッシュは公式pruneを使用し、使用中・リンク・用途不明の対象は残します。削除結果はrecordsへ保存します。

## 結果と制約

既存データは一覧とSHA256を記録してから移動し、照合します。旧パスへのフォールバック、二重保存、自動保持期限は設けません。GPUの一時配置はGpuPathsで独立させ、ローカルとGPUの同じ用途の対応をテストします。バックアップ先の選択と保管は利用者が行います。
