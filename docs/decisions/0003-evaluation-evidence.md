# ADR 0003: 生成・評価・観測を分離する

状態: 採用済み

## 背景

過去の生成から改善するには、条件と画像に加えて比較対象、基準、評価者、根拠が必要です。AIの判定にもモデルと指示の識別情報が必要です。

## 決定

JSONとローカルファイルを正本とし、評価は追記します。生成時の事実を後の評価で変更しません。新たなファイル確認は観測情報として扱います。

保存場所はWorkspacePaths、実体はArtifactStore、履歴と評価は用途別リポジトリで扱います。IDは記録の識別、SHA256は内容の識別に使います。SSH状態・キャッシュ・品質記録は同じ保存契約へ統合しません。

## 結果と制約

分析用出力は条件・来歴・評価・画像参照とスキーマを含みます。評価API、外部送信、改善案の適用は明示的な後続操作です。DBや実験管理ツールは保存契約を利用する後続機能として扱います。
