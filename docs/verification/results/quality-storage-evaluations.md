## 保存と評価の検査

| 対象 | 結果 |
|---|---|
| 通信中の排他 | 画像・素材の取得待ち中に共通の状態更新ロックを取得可能 |
| 並行回収 | 同じ要求の二重取得を防ぎ、保存状態の後退なし |
| 終了との競合 | lost確定後の画像・素材の到着で状態を再開せず、素材の保存通知も送信しない |
| 部分失敗 | 異常画像と正常画像が混在しても正常分を保存し、失敗分を再回収可能 |
| セッション切替 | 古いセッションの観測で新しい接続の状態を変更しない |
| 品質記録 | 累積レベル、個別検査、失敗・中断・入力変更、最新実行と最新成功の保持を確認 |
| 評価 | 人・AIの来歴、採否・選好、参照検証、訂正の追記、一括入力、未評価の生成を含む出力を確認 |
