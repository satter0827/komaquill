# ローカルLLMの動作と精度を比較する

## 目的と前提

同じ原文・描画方針・画像に対して、4Bと9Bの実行可否、応答、処理時間、使用メモリを比較します。計画の形式と意味、画像の保存と採否を分けて評価します。複数候補の自動生成・自動採用は製品機能として追加しません。

WindowsのLM Studio、公式CLI、LLM追加依存を導入した開発環境を使用します。手元に両モデルのQ4_K_Mと対応する画像用ファイルが必要です。元のロード状態もCPU実行であることを確認してください。Local Serverを127.0.0.1:1234で起動し、他の推論を終えてから実行します。モデルは一つずつロードし、他のアプリや未知のモデルを停止しません。Colabは使用しません。

## 入力を固定する

画像のmanifestは非公開の.artifacts/records/reports/llm-comparisonへ保存します。画像ごとにid、task、scene、image、sha256、criteriaを保持します。criteriaはid、statement、expectedを持ち、期待判定はmatch・mismatch・unclearです。二画像の比較はtaskをpairとし、imageの代わりにimagesへ順序付き参照を保存します。期待ラベルは採点用で、モデルへ送信しません。

画像参照は作業フォルダー内の.artifacts/dataに限定します。画像は再生成・複製せず、事前に内容ハッシュとラベルを固定します。ラベルの作成者、根拠、未確認事項を明記します。合格例がなければ良品の採用能力を確認できたとは扱いません。

## 明示的に実行する

プロジェクトのPython環境を有効にして実行します。manifestには実際の入力ファイル、reportにはまだ存在しない出力フォルダーを指定します。

```powershell
python -B -m tests.live.llm_comparison --allow-real-llm --project . --manifest .artifacts/records/reports/llm-comparison/inputs/image-cases.json --report .artifacts/records/reports/llm-comparison/result
```

入口は[実機比較](../../tests/live/llm_comparison.py)、調整と判定は[検証用処理](../../tests/support/llm_comparison.py)です。通常のpytestと品質ゲートには実測を含めません。許可フラグがない場合は接続しません。

ロード前に元のモデルと実効設定を保存します。既存モデルのアンロード後に必要メモリとコミット余裕を確認し、余裕が不足する場合は停止します。両モデルのコンテキスト、並列数、CPU実行を揃えます。8192で9Bのロードに失敗した場合のみ、4096で画像評価だけを確認します。ロード後の推論失敗では自動的にコンテキストを変更しません。

計画は3題材の固定4枚と自動枚数、修正は最大1回です。画像は個別判定と候補順を入れ替えた比較を行います。実測は90分以内とし、未実施の条件は未実施として保持します。終了・例外・Ctrl+Cでも元のロード状態へ戻し、実効設定の一致を確認します。PCの電源断など、処理を継続できない中断ではoriginal.jsonを確認し、元のモデルと設定を復元してください。

## 記録と判断

results.jsonは条件ごとの成功・失敗・未実施と復元結果、各JSONは入力・応答・判定、memory.jsonlはメモリとプロセスの観測です。control.jsonlは制御の引数・終了コード・見積もり値に限定し、CLIの生出力や例外本文を診断へ転載しません。

初回と修正後の成功を分け、成功時だけでなく失敗も含めた呼び出し数・トークン・時間を使います。内容はblind-plans.jsonでモデル名を伏せて確認し、評価を固定した後にblind-map.jsonでモデルへ結び付けます。モデルの既定値など確認できない条件は不明として記録します。

9Bのロード成功と精度向上は別の結論です。同等以上の精度で実用動作する用途では9Bを優先し、悪化・不明・基準未達も残します。少数例から改善率や統計的優位性を断定しません。通常利用の既定モデル変更は、この判断を記録した後の別の変更として扱います。

個別画像はsha256文字列、二画像の比較は画像参照をキーとするsha256の対応表を指定できます。比較画像が個別画像にも含まれている場合、そのハッシュを利用します。送信前に固定したハッシュと照合し、内容が変わっていたら送信しません。

集計は`tests.support.llm_report.summarize`を使い、応答なしの使用量と未実施を区別します。終了コード0は測定・復元の完了であり、モデルの採用や精度合格を表しません。[対象版の結果](../verification/results/llm-comparison.md)を確認してください。
