# 視覚設計と共通操作の検証

対象: REQ-WEB-VISUAL-IDENTITY、REQ-CONVERSATION-ALBUM-UX、REQ-WEB-ACCESSIBILITY。

## 対象と方法

2026年11月5日、Windowsで確認する。基準版は9c32023。配色、共通操作、保存済み画像の表示を変更し、公開API、保存形式、モデルの既定値と生成条件は変更しない。自動検査は隔離した作業フォルダーと擬似API、実LLMの確認は別の作業フォルダーで行う。

## 発見と修正

| 問題                                           | 原因と修正                                                                                   |
| ---------------------------------------------- | -------------------------------------------------------------------------------------------- |
| 小窓の配置とフォーカスが画面別に実装されている | Base UIのDialogとPopoverへ委譲し、行動追加後の発言欄への復帰も公開APIを使用する              |
| 行動の版確認と外見確認が閉じた領域へ隠れる     | 送信待ちの要約と会話履歴へ必要な確認を表示する                                               |
| 未保存の物語メモが小窓を閉じると消える         | 小窓を閉じたときにフォームが破棄されていた。メモの部品を保持し、入力と保存確認を維持する     |
| 非表示中に画面幅を変えると内容が再表示される   | 非表示の状態がナビの寿命に依存していた。状態とDialogを上位へ移し、ナビの切替から分離する     |
| モバイルで非表示から復帰するとフォーカスを失う | ポータル内の復帰操作がナビへ伝播してナビを閉じていた。リンクの遷移だけで閉じる構成へ変更する |
| 最新の返答への操作が会話欄を押し縮める         | 返答への導線を配置領域から分離し、過去を読む位置と領域の高さを保つ                           |
| 入力欄のフォーカス枠が二重になる               | 入力欄の外枠にフォーカスを表示し、内側の重複枠を除く                                         |

再現前の観測は`.artifacts/records/reports/cherry-ui-20261105/lifetime-before.json`へ保存した。修正後の同じ条件は通常のPlaywright回帰テストへ追加した。

## 実LLMの確認

LM Studioの取得済み4Bモデルを使用し、日本語の発言、日本語の発言と待機行動、英語への切替をアプリの画面から送信した。3往復がcompleteとなり、待機行動は1件、経過時間は5分だった。4回のモデル呼び出しには、英語の動作記述を修正する1回を含む。新しい操作の再送は行っていない。

原応答、送信内容、使用量、ファイルのハッシュと操作IDは隔離した`.artifacts/records/reports/cherry-ui-20261105`へ保持する。画像生成とGPU確保は行っていない。今回起動したローカルモデルをアンロードし、LM Studio APIを停止した。

この結果は短い会話とUIの結合確認であり、モデルの品質全体や長期の人物一貫性を保証しない。保存済みの日本語の情景は、表示言語の切替で翻訳せず保持した。
